SOUTHAMPTON REFINE — NOTES
Updated: 11 October 2026 (Europe/London)

PURPOSE
Improve the existing 1:1 Geocraft LIDAR world of Southampton so buildings,
street furniture, water edges and materials match the real place, using
ground photos, aerial imagery and authoritative surveys. No fictional
districts, themes or whimsy — accuracy only.

START HERE
- PROCESS.txt: cadence, one-builder lock, plan → apply → readback.
- QUEUE.txt: ordered work items (one per chat).
- PLACES.txt: real places being refined (OSGB + Minecraft coords).
- ISSUES.txt / REVIEWS.txt: snags and review log.
- TODO.txt: smaller tasks and session notes.
- HANDOFF.txt: starter for the next chat.
- config/world.json: path to the Southampton2023 save.
- config/map-maker-offsets.json: OSGB36 ↔ Minecraft transform.

WORLD
- Source world: Southampton2023 (Geocraft UKDEFRA LIDAR + OSM).
- Grid: OSGB36. OFFSET_E=436248, OFFSET_N=109608 (see config/).
- Minecraft: +X = east, −Z = north. SEA_LEVEL=11 (Geocraft).
- Bounds (MC): X 0..11604, Z −8666..0.
- Convert with: python3 scripts/osgb.py …

COORDINATE RULE
Always record both OSGB (E,N) and Minecraft (X,Y,Z) for a place. Never
guess offsets — use scripts/osgb.py and the map-maker status.

ACCURACY RULES
1. Match real footprint, height band and openings before decorating.
2. Materials should read as the real surface (brick, stone, render, roof
   type) within Minecraft’s palette — not a fantasy substitute.
3. Prefer small, reversible kit builds with backup + cells archive.
4. Do not “improve” or invent features absent from evidence.
5. LIDAR is the height authority; photos resolve façades and details.

WISDOM KEPT FROM THE TOWN KIT (without town fiction)
- One builder at a time (site/LOCK.json).
- Files are memory; one queue item per chat.
- Plan offline → preview PNG → dry-run guards → apply → readback → walk
  → contact-sheet views → records.
- Never edit a BUILT plan in place: write a new modification build that
  declares what it modifies.
- Modifications come from the cells archive, not from regenerating a plan
  that re-reads terrain as if it were virgin.
- Fill unloaded chunks silently fails — hop the player near the box.
- Posts (fence/wall/bars) must not float on bottom slabs / carpets.
- Review via contact sheets; open full-size views only for detail.
- Batch anything that needs the user into one ask; do not poll.
